# ProstoChess — сайт

Статичний сайт (HTML, CSS, JS без збірки): `index.html` (Головна), `about.html` (Про мене), `reviews.html` (Відгуки).
Дизайн-система: `DESIGN_SYSTEM.md`. Референси: `design/references/`.

## Що де міняється
- **Посилання для запису:** `BOOKING_URL` на початку `js/main.js`. Зараз `https://t.me/dan_chess`. Всі кнопки «Записатись» беруть його звідси.
- **Фото:** `assets/portrait.webp` (PNG/WebP з прозорим фоном). Використовується на Головній, «Про мене» і «Відгуки». Якщо файлу немає, показується силует пішака.
- **Відгуки:** `js/reviews-data.js` і скріншоти в `assets/reviews/`. Записи з `image` крутяться по орбіті навколо фото на сторінці «Відгуки» і потрапляють у сітку нижче. Орбіта вимикається при `prefers-reduced-motion`, сітка лишається.

## Локальний запуск
`npx http-server .` і відкрити http://localhost:8080
