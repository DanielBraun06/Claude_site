# ProstoChess — сайт Данііла Коваленка

Статичний сайт: `index.html` (головна), `reviews.html` (відгуки), `styles.css`, `main.js`, `assets/`.

## Що заповнити
У верхній частині `main.js`:
- `CONFIG.bookingUrl` — куди ведуть усі кнопки «Записатися» (наприклад, Telegram);
- `CONFIG.socials` — посилання на соцмережі у футері;
- `REVIEWS` — реальні відгуки (текст, ім'я, за бажанням скрін і аватарка).

Запуск: просто відкрити `index.html` у браузері. Деплой — будь-який статичний хостинг (GitHub Pages, Netlify, Vercel).
